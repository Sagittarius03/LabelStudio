# Label Studio

Настольный редактор макетов этикеток для Windows 10/11. Интерфейс на русском, печать через установленный драйвер принтера (в том числе BarTender), загрузка одного CSV/XLSX-файла на тираж и шаблоны в JSON.

## Запуск для разработки

Требуется Python 3.11+ и [uv](https://docs.astral.sh/uv/).

```powershell
uv sync
uv run main.py
```

`uv sync` создаёт `.venv` и ставит зависимости по `uv.lock`. Для локальной сборки Windows приложения: `uv sync --group build`, затем `uv run pyinstaller --noconfirm --clean --windowed --name LabelStudio --add-data "logodeveloper.svg;." --collect-all pystrich --collect-all qrcode --collect-all barcode main.py`.

GitHub Actions собирает Windows portable EXE и установщик Inno Setup при создании тега `v*`.

## Возможности первой версии

- Макет с текстом, Code 128, QR, DataMatrix, линиями, геометрическими фигурами и символами; переменные берутся из столбцов выбранного файла.
- Для штрихкода настраиваются расположение номера, выравнивание и размер подписи; для текста — семейство шрифта, размер, начертание, цвет и выравнивание.
- Для GS1 DataMatrix доступны извлечённые GTIN и серийный номер как поля шаблона.
- Нумерация `{SEQ}` настраивается вверх/вниз, с начальным значением и разрядностью.
- Размеры этикетки и координаты объектов задаются в мм с тремя знаками после запятой; объекты и этикетку можно поворачивать.
- Сетка, перетаскиваемые направляющие и магнитное выравнивание объектов по краям и центрам соседних объектов.
- Объекты можно растягивать маркерами на рамке и выравнивать по краям или центру этикетки.
- Импорт CSV и XLSX с выбором листа/столбцов, строки заголовка и начала данных; для CSV настраиваются разделитель и кодировка. Автоимпорт сохраняет GS1-коды целиком, а предпросмотр показывает все прочитанные строки с прокруткой.
- Отдельная область предпросмотра тиража показывает номер этикетки, общее количество и вид конкретной записи с переменными.
- Предпросмотр можно переключать по строке тиража и по номеру варианта; при нумерации отображается выбранное значение счётчика.
- Свойства объектов сгруппированы по вкладкам «Данные», «Размер», «Текст» и «Код».
- Панели объектов, свойств и тиража можно перетаскивать, менять их размер и откреплять в отдельные окна; панели не закрываются, раскладка сохраняется между запусками. Меню «Вид» восстанавливает начальное расположение.
- В текст, QR и штрихкод можно вставлять переменные из CSV/XLSX, `{SEQ}`, а также `{GTIN:ИмяСтолбца}` и `{SERIAL:ИмяСтолбца}`.
- Ручной шаблон печатается без таблицы данных; CSV/XLSX нужны только для подстановок из строк.
- Подключённый файл тиража можно отвязать и печатать макет с заданным количеством и нумерацией.
- Один пакетный документ с несколькими страницами отправляется в очередь Windows одним заданием.
- Шаблон можно сохранить в отдельный JSON-файл; Ctrl+S сохраняет текущий файл, Ctrl+Shift+S открывает «Сохранить как».

## Горячие клавиши

| Действие | Клавиши |
| --- | --- |
| Новый / открыть / сохранить шаблон | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` |
| Печать тиража | `Ctrl+P` |
| Добавить текст / штрихкод / QR / DataMatrix | `Ctrl+Shift+T` / `Ctrl+Shift+B` / `Ctrl+Shift+Q` / `Ctrl+Shift+D` |
| Удалить выбранный объект на холсте | `Delete` |
| Сдвинуть объект на 0,1 мм | `←` `↑` `→` `↓` |
| Сдвинуть объект на 1 мм | `Shift` + стрелка |
| Повернуть объект на 90° | `Ctrl+Alt+←` / `Ctrl+Alt+→` |
| Повернуть этикетку на 90° | `Ctrl+Shift+Alt+←` / `Ctrl+Shift+Alt+→` |
| Добавить вертикальную / горизонтальную направляющую | `Ctrl+Alt+V` / `Ctrl+Alt+H` |

Перед рабочей печатью проверьте выбранный размер носителя и драйвер на тестовом тираже: у разных драйверов отличаются настройки калибровки и резки.
